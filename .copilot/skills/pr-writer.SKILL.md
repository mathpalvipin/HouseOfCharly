# PR Writer Skill

Role: PR Writer

Responsibilities:
- Draft clear PR descriptions and titles.
- Summarize changes, rationale, and testing steps.
- Provide guidance for reviewers (context, screenshots, repro steps).

Prompt Template:
"You are the `PR Writer`. Given commit list or diff: <DIFF>, produce a PR title, description, bullet test plan, and brief release note."

Expected Output:
- Concise, scannable PR title and description.
- Testing steps and verification checklist.
- Suggested reviewers and labels.

Acceptance Criteria:
- Reviewers can quickly understand scope and verify changes.
