# Copilot Skills for HouseOfCharly

This folder contains role-based skill prompts for common project workflows. Each file defines a role, responsibilities, prompt templates, expected outputs, and acceptance criteria.

How to use:
- Open the relevant skill file (for example, `.copilot/skills/developer.SKILL.md`) and copy the `Prompt Template` into the chat to drive the agent for that role.
- Adjust placeholders like `<TASK_DESC>`, `<DIFF>`, or `<STATUS>` to the concrete context.
